Much of what a language model does inside a production system is not writing but deciding: which model should answer, whether a cached answer can be reused, which tool to call next.
A new class of non-generative ``decision models'' returns a typed, calibrated choice instead of text and is marketed as a far cheaper replacement for an LLM at these points.
We test that claim on one harness with interchangeable deciders (a frontier LLM, small hosted and self-hosted LLMs, a proprietary decision model, an open-weights reproduction of it, and trained classifiers) at three decision points, measuring quality, cost, latency and GPU energy.
The decision model pays off as a semantic-cache guard, which decides whether a stored answer can be served for a new query: on near-identical math questions whose answers differ, it decides correctly 93.3\% of the time where a similarity threshold reaches 66.1\%, at about 2\% of the frontier model's price per decision.
It does not pay off for agent tool choice, where letting the generator decide inside its own call is cheapest at equal task reward, or for model routing, where a small classifier trained on the cheap model's record beats every general decider.
A separate decider is therefore worth its call when the decision avoids a generation and the evidence it needs is in the input.
