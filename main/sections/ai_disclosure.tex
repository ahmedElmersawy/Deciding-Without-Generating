\section*{AI Usage Disclosure}

We used generative AI tools extensively in this work, mainly Claude Code (an agentic coding assistant) running Claude Opus 5.5, and Claude Sonnet 5 for a few coding tasks.
We describe each use below.
The authors directed every step, reviewed all output, and take full responsibility for the code, the results, the citations, and the text.

\textbf{Ideation and experiment design.}
The research question, the three decision points, the set of deciders, and the vendor claims to test come from a project plan the authors wrote before any AI assistance.
During the work we used the assistant to discuss design alternatives and to check the evaluation protocol for leakage and confounds, for example the tie-breaking and the clustered bootstrap.
The authors made all design decisions.

\textbf{Literature search.}
The assistant helped find related work and prepare bibliography entries.
The authors checked every cited work against its original source: that it exists, that its authors and venue are correct, and that it supports the claim it is cited for.

\textbf{Code.}
The assistant wrote most of the code under the authors' specification: the shared decider interface and its adapters, the harnesses for the three decision points, the cluster job scripts, the energy measurement, the analysis and bootstrap scripts, and the scripts that produce every figure and table.
The authors reviewed the code and checked its outputs against hand-computed cases and raw run logs.
The code is released with the paper.

\textbf{Running experiments.}
The assistant helped launch, monitor, and debug jobs on our GPU cluster and diagnosed integration failures with hosted APIs.
Every reported number comes from logged runs, which we release.

\textbf{Data.}
Claude Opus 5.5 relabeled the query pairs of the two vCache datasets under a guideline we fixed in advance (Section~\ref{sec:cache}; Appendix~\ref{app:labels}).
This relabeling is part of the method, and its limits are discussed there.
No other data was generated by AI.

\textbf{Writing.}
The assistant drafted the text of the paper from the authors' results, outlines, and instructions, and carried out editing passes against a written set of review rules for clarity, consistency of numbers, and the page limit.
The authors reviewed and revised every section and every change, and checked each claim against the results.

\textbf{Models under study.}
The decision models and LLMs evaluated as deciders (Section~\ref{sec:method}) are the objects of study.
Calling them is part of the experiments, not assistance in producing the paper.
